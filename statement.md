# Project Statement

## Problem Statement

Keeping track of daily expenses can become difficult when expenses are written down in different places or are not recorded at all. It can also be difficult to know how much money has been spent in total or which categories take up most of the spending.

This project is a simple Python-based Personal Expense Tracker that allows users to record and manage their expenses from the terminal.

## Project Objective

The main objective of this project is to create a simple program that helps a user keep track of personal expenses.

The project also helps me practice Python concepts such as classes, functions, file handling, input validation, error handling, modules, and basic testing.

## Target Users

The main target users are people who want a simple way to keep track of their personal daily expenses.


## Scope of the Project

The project currently focuses on basic personal expense management.

The user can:

- Add expenses
- View saved expenses
- Delete expenses
- Search expenses by category or description
- View total spending
- View category-wise spending
- Save expenses to a CSV file
- Load previously saved expenses

The project is currently a command-line application and does not include a graphical interface or online database.

## High-Level Features

### 1. Expense Management

The user can add, view, and delete expenses.

Each expense contains:

- Date
- Category
- Description
- Amount

### 2. Search and Analysis

The user can search expenses using a category or description.

The program can also calculate the total amount spent and show spending category-wise.

### 3. Data Storage

The expenses are stored in a CSV file so that the data can be loaded again when the program is started.

## Expected Outcome

The expected outcome is a working command-line Personal Expense Tracker that can store and manage expense information and provide a basic summary of spending.
